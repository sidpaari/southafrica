# southafrica
sabbatical recap html

## Getting Started

This is a simple static HTML site recapping a sabbatical in South Africa.

### Local Development
- Open `index.html` in your browser to view the site.

### Hosting on GitHub Pages
1. Push this repository to GitHub.
2. Go to repository Settings > Pages.
3. Set source to "Deploy from a branch", select `main` branch and `/ (root)` folder.
4. Save. The site will be live at `https://<username>.github.io/southafrica`.
